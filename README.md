# PixelPulse

PixelPulse is a responsive image discovery app powered by the Wikimedia Commons API. Search for a topic to explore community contributed images.

## Live app

https://prabhaskodela.github.io/PixelPulse/

## Features

- Loading spinner and animated placeholder cards while images load
- Clear empty and error messages
- Result count and responsive masonry layout
- Image titles and contributor credits

## Run locally

Open `index.html` in a browser. The app uses plain HTML, CSS, and JavaScript; no build step or API key is required.

## Deployment

GitHub Actions deploys the site to GitHub Pages when changes are pushed to `main` or `part-3-polish-deploy`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

Images are provided by Wikimedia Commons and remain subject to their respective licenses.
